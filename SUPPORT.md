# Getting help

This project is open-source software with community-and-paid support. Use the right channel for the right question.

## Free / community support

| What | Where | When to use |
|---|---|---|
| Usage questions, deployment help, "how do I…" | [GitHub Discussions](https://github.com/pandora-cloud/govwin-hubspot-ace/discussions) | Default starting point for any question that isn't a confirmed bug or a security issue. |
| Confirmed bugs | [GitHub Issues](https://github.com/pandora-cloud/govwin-hubspot-ace/issues) | You can reproduce a defined defect. Include redacted logs and steps. |
| Feature requests | [GitHub Issues](https://github.com/pandora-cloud/govwin-hubspot-ace/issues) | The feature serves federal AWS partners running this pipeline. |
| Security disclosures | [Private security advisory](https://github.com/pandora-cloud/govwin-hubspot-ace/security/advisories/new) or `pc@pandoracloud.net` | Credentials, vulnerabilities, ACE submission integrity, supply-chain concerns. **Never** open a public issue. See [SECURITY.md](SECURITY.md). |

Response time for community support is best-effort. Expectations:

- Discussions: best-effort, no SLA.
- Issues: 5 business days for first response.
- Security: 7 calendar days for first response, 30 days for fix or mitigation.

## Commercial support

If you need deployment assistance, prioritized feature work, or guaranteed-response incident support that exceeds what an open-source project can sustain, the maintainers offer paid engagements. Contact <pc@pandoracloud.net> to discuss scope and terms.

## What this project does not cover

The maintainers will not provide free support for:

- Forks that have been substantially modified, where the modifications are the source of the bug.
- Commercial integration scenarios where the support effort exceeds what an OSS project can sustain.
- Adapters for non-supported CRMs (Salesforce, Pipedrive, Dynamics, etc.). Those are out of scope per [CONTRIBUTING.md](CONTRIBUTING.md).
